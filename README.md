# 柏宝绘 · SillyTavern 剧情配图助手

> 让 AI 的每一段精彩剧情都有画面。柏宝绘会一边陪你聊，一边默默判断「这一幕值不值得画」，自动挑选最值得定格的瞬间、写好生图提示词，再交给出图渠道生成图片，直接嵌进楼层里。全程自动，也可随时手动接管。

光有文字的故事总觉得少了点什么——角色长什么样、战斗场面有多燃、告白那一刻的光线，都只能靠脑补。柏宝绘就是为了把「脑补」变成「亲眼看到」而生的：它不打扰你聊天，只在恰到好处的时候递上一张图。

---

## 手机 / 局域网取图

ComfyUI 渠道的「取图格式」默认选 **JPG 轻量传输**：从 ComfyUI 的 `/view?preview=jpeg;92` 获取同尺寸 JPEG，质量 92，不携带 PNG 工作流元数据。ComfyUI 本地保存的原始文件保持不变；动画格式保留原格式。也可以手动选择「原始格式」。

- 浏览器直连时，连接检查和提交按调用顺序排队；收到前一张任务 ID 后提交下一张，不等待生成完成。图片下载仍逐张执行。
- `/history` 查询、图片下载或响应体读取出现短暂网络错误时，沿用原任务 ID / 文件地址自动重试最多 3 次，间隔 0.75、1.5、3 秒，不再次提交生图。401 等确定性错误及工作流执行错误直接返回。
- 自动重试耗尽时，错误保留原任务 ID；楼层原有「生成」按钮仍表示重新生图，不是继续取回原任务。刷新页面后不恢复未完成的下载队列。
- JPG 模式需要浏览器可直连 ComfyUI。启动 ComfyUI 时添加 `--listen 0.0.0.0 --enable-cors-header`，手机地址填写电脑的局域网 IP 与 8188 端口。测试连接应显示浏览器直连。
- 原始格式可沿用酒馆 / Tauri 的后端转发；由于该接口把提交、查询和下载合在一次请求中，这条路线逐个执行整个请求。转发错误包含原 `/history/<id>` 或 `/view` 地址时，仅尝试从原地址直连取回结果；仍需浏览器可访问。JPG 模式在直连不可用时会在提交前提示配置，不静默改传 PNG。

## 它能做什么

### 🖼️ 自动配图，精彩瞬间不错过
- **自动分析剧情**：每次 AI 回复后，柏宝绘会通读这段剧情，判断有没有值得画的瞬间——有就画，没有就安静跳过，绝不刷屏。
- **自动编写提示词**：英文正向 tag、画面描述、画幅方向、负面词全都自动写好，你几乎不用碰提示词。
- **一次多张**：想多要几张也可以，单次最多可规划多张图，按剧情节奏依次生成。
- **手动接管**：想指定某一楼出图？点楼层上的「生成 tag」按钮即可；写好的 tag 也会直接显示在图片卡片上，随时能看能改。

### 🎭 角色固定外貌库：外貌永不漂移
- **首次出场自动建档**：有名有姓的正式角色第一次出场，柏宝绘会自动记下他的发色、瞳色、体型等固定外貌，之后每一张图里的他都长一个样。
- **只报名字，不抄外貌**：AI 在提示词里只需写「@角色名」，插件会机械替换成档案里最新、最准确的外貌——彻底杜绝「这一楼金发、下一楼黑发」的漂移问题。
- **永久变化自动更新**：角色染发、剪发、留疤、长大……这些永久变化会被自动记进档案，且**按剧情位置生效**：变化之前的图片用旧外貌，变化之后用新外貌，时间线不错乱。
- **临时状态不混淆**：假发、湿身、包扎这类临时状态不会污染档案，但同一场景里会持续保持，直到剧情解除。
- **手动编辑与回滚**：档案随时可以手动修改、删除；每次 AI 的自动变更都有记录，一键回滚。
- **全局角色库**：玩家角色等「哪个聊天都用同一张脸」的角色，在角色管理页一键「提升为全局」——之后所有聊天自动生效，无需重复建档。全局角色是冻结档案：AI 永远不会修改它，完全由你手动维护；某个聊天想让他不一样，复制回本聊天即可覆盖。

### 🎨 出图渠道：ComfyUI 与 NovelAI
- **ComfyUI**：两种配置方式任选——**简易参数**模式直接选模型/LoRA、填步数等基础参数即可出图（内置 Checkpoint 系/Flux/Anima/MOSS-Image 模板，模型列表一键从 ComfyUI 拉取）；**自定义工作流**模式加载你自己的 API 工作流模板，占位符自动填充 tag、描述与尺寸，节点怎么连不用操心——**AI 会自动定位**该填哪个节点、哪些片段要保留，应用前还能预览改动。
- **LoRA 文件选择**：简易参数中的 LoRA 支持下拉搜索和手动输入；打开空列表时自动尝试读取 ComfyUI 清单，读取失败或后端未提供清单时给出明确提示。
- **多套工作流随时切换**：常用的工作流可以各存一套、各起名字，下拉一点就换。自然语言开关与横竖尺寸都跟着工作流走——二次元底模和 Flux 之间来回切，不用再逐项改设置。
- **固定横图 / 竖图**：每个渠道的尺寸旁边都有「画幅方向」：自动 / 竖屏 / 横屏。锁定后每张图都按这个方向出，AI 写提示词时也会按这个画幅去构图，不用再把横竖尺寸填成一样来凑（ComfyUI 每套工作流各设各的）。
- **NovelAI**：官方 v3 / v4 / v5 系列模型；支持 vibe 参考图（角色风、画风参考）；`.naiv4vibe` 文件与官方互通，导入导出都行。
- **NAI 多接入点随时切换**：官方站与各个第三方站可以各存一条、各起名字、各记各的 Key，下拉一点就换。换站只换出口——模型、采样器、尺寸、vibe、画师串这些参数全部照旧，不用重配一遍。官方那条是内置的，地址固定不用填。
- **NAI 自然语言可开可关**：NAI 4.5 的提示词有长度上限（画面与所有角色共用约 512 token），自然语言描述最占篇幅，超出的部分会被截掉、画面跟着走样。觉得 4.5 画得怪，可以在 NAI 渠道里关掉「生成自然语言」，让 AI 只写 tag 试试。
- **渠道灵活**：可以指派专门的副 API 渠道去跑生图，不占用主对话；不配置就跟随主 API。
- **画师串随时切换**：常用的画风/画师组合可以各存一套、各起名字，下拉一点就换，也可以选「不使用」。选中的画师串会拼在提示词最前面，整幅画的画风基调一次定好。
- **负面词、质量词智能默认**：每个模型都有官方推荐的质量词与负面词，点开就能看到实际生效的内容；想改就改，改完会标记「已自定义」，随时一键恢复默认。

### 📁 图片管理，随聊随存
- **内嵌楼层卡片**：生成好的图片直接嵌在对应楼层下方，与剧情一一对应。
- **显示大小可调**：电脑宽屏上嫌楼层里的图太大？设置页「楼层图片显示大小」有小 / 中 / 大 / 铺满四档。只改聊天里显示多大，不影响出图分辨率，图片文件原样不动。
- **点击放大、长按保存**：灯箱查看大图，长按图片即可保存到本地。
- **出图信息可回溯**：每张图随图记录完整提示词、画师串、vibe（含强度）、模型与采样参数；在灯箱或图库里点开就能看到当时到底怎么画的——喜欢的图再也不会忘记用的哪套配方。
- **重新生成与取消**：对某张图不满意，点一下重绘（同提示词再出一张）；觉得提示词写得不到位，打开铅笔（编辑提示词）弹窗，里面既可以自己改，也可以点「AI 重写提示词」让它重读剧情把这一张的提示词重写一遍再出图——只动这一张，同楼其它图片不受影响。重写期间可以放心关掉弹窗，生成不会中断，回头再打开还能接着看；想整楼重新选画面则用消息 ⋯ 菜单里的调色盘按钮。生成中也可以随时取消，不浪费额度。
- **智能队列**：多张图排队生成，并发数可调，不会把渠道挤爆。
- **可选 JPG 转存**：需要更小的文件体积时，可让 PNG 自动转存为 JPG。

### 🤝 与柏宝书无缝协作
- 柏宝绘读取柏宝书的角色状态与剧情记忆，让配图与「此刻的剧情」严丝合缝。
- 不想被某段内容打扰？**排除名单与柏宝书共享**——按角色、按世界书整本或按条目名排除，两端同步，一处设置两边生效。

### ⚙️ 想调多细都行
- **提示词全可编辑**：破限、生图规范、思维链……每一套都有内置默认，也可全部自定义。规范与思维链里还能用 `{{#nl}}…{{/nl}}` / `{{^nl}}…{{/nl}}` 写只在开 / 关「生成自然语言」时生效的段落，一份提示词两种模式都顺。
- **多主题界面**：自动跟随 SillyTavern 配色，手机、平板、电脑都顺手。
- **自动更新**：有新版时导航栏亮起小红点，设置页一键更新并自动刷新。

## 安装

### 专用世界书（可选）

「设置 → 专用世界书设置」可以选择酒馆已有的书，仅供柏宝绘扫描，无需挂到酒馆全局。条目的蓝灯常驻、绿灯关键词及其他触发条件沿用酒馆原扫描器；启用后只读取专用书单，关闭后跟随酒馆当前书单，现有排除名单仍生效。

本功能需要一次性安装宿主扫描兼容补丁：在插件目录运行 `node scripts/patch-worldbook-scanner.mjs --check`，确认兼容后运行 `node scripts/patch-worldbook-scanner.mjs --apply` 并刷新酒馆。脚本先备份再修改，不改变酒馆全局书单；酒馆升级后可能需要重装。完整说明见[专用世界书](docs/dedicated-worldbooks.md)。

### DSH 持久 Agent 会话（可选）

在「设置 → 副 API」指派 DSH 接口渠道并开启「DSH 持久 Agent 会话」。固定前缀、提示词规范、宿主协议和检查指导只在首次发送，之后通过「重新发送固定规范」手动更新；世界书、角色资料、上下文与目标正文每次发送。每个酒馆聊天独立绑定会话，刷新页面后继续，模型返回由 DSH 自己保留，插件不回传。可通过「重建 DSH 会话」重新开始。

此功能默认关闭，需要 DSH 实现持久会话扩展，普通 OpenAI 兼容接口不会自动获得上下文。接口字段、控制操作及联调清单见 [DSH 接口说明](docs/dsh-session-bridge.md)。

### MOSS-Image 漫画 Layout（可选）

在设置中开启「漫画 Layout」，使用「渠道 → 简易参数 → MOSS-Image(Qwen3.5-9B)」，或支持 MOSS 原生 Layout 的 ComfyUI 自定义工作流。
MOSS 简易模板固定使用 `moss_image` 文本编码器类型与 Flux2 潜空间，请分别选择 MOSS 模型、Qwen3.5-9B 编码器和 Flux2 VAE。它是新增选项，不改变默认模板或已有预设；包含专用加速、文本编码器 LoRA 等复杂节点时继续使用自定义工作流。
插件内置 18 套横竖版式，可分别启用、停用、修改用途说明，或用 JSON 添加和覆盖版式。
漫画规范与检查指导可单独配置，关闭漫画开关后回到常规配置。

点击「快捷自定义」可打开可视化编辑器，从空白创建，或复制已有版式后拖动、缩放分格。
列表中的「可视化编辑」更新原版式。左侧「提前／延后」调整读序，「上移一层／下移一层」独立调整遮挡层级；越靠前的格子覆盖后方重叠区域。层级随版式保存，插件在整页描述开头集中写入外框、读序和英文遮挡关系，各内容项保留简短的所属格说明，不再重复整套层级描述；这是模型构图提示，不是像素级遮罩。
支持自填画布宽高（64～8192 的偶数）、矩形嵌入与重叠、对齐吸附、精确坐标、读序调整和撤销重做。新增分格默认只有 F 外框；左侧「一键添加所有槽位」为选中分格补齐默认内框，保留已有槽位的位置、形状和说明，支持撤销与重做。
取消与保存按钮位于右上角 X 左侧；编辑现有版式可保存修改，新建版式另存为自定义版式。画布尺寸随版式保存，工作流与当前方向预设须配置成相同尺寸。

版式列表上方的「批量修改画布大小」可输入宽高，一键调整当前全部版式（含停用项）。横竖方向保留：例如 1664×2496 对应横版 2496×1664，所有外框、内框和四角形变坐标按比例缩放；格号、读序、层级、用途及删除记录保留。同一 ID 的横竖版共享这对宽高，编辑其中一个方向的尺寸时，另一方向的已有坐标同步缩放。可立即撤销本次批量调整；继续修改其他版式后撤销按钮失效。工作流及渠道方向尺寸需同步为对应画布大小。
人物、文字等内部槽位可独立移动、缩放和删除；普通拖动四角或边中点缩放，按住 Ctrl 再拖四角才改变四边形轮廓。
选中外框或内部槽位后，可在右侧填写“当前框用途说明”：F 说明整格的叙事用途，其他槽位各有独立说明。保存版式后，说明会按格号与槽位加入发送给规划 LLM 的版式清单，帮助分配内容；不直接拼入生图 JSON，也不作为图中文字。说明支持复制、撤销和内框确认／取消，删除槽位时同时移除其说明；留空沿用原有槽位用途。
文字区提供 TL/TR 左上与右上、BL/BR 左下与右下，快捷新建还提供 ML/MR 两侧字区。旧自定义版式首次升级时从现有 B 补齐 BL/BR，之后删除不会自动补回；无 B 的格子不凭空增加底部字区。气泡按实际发言创建，沉默一侧不填空气泡；同一矩形字区的多条文字按输入顺序分成独立上下区域。非矩形字区应分别分配文字，重复引用会提示换区或拆格。避脸与关键动作保护通过构图说明引导，不是自动人脸避让。
编译器按实际非空 text 项追加通用文字布局说明；纯画面输入省略这段说明，保留版式库中的可用字区。仅拟声页沿用拟声字样和各项自己的容器描述，编译器不再固定追加对白气泡描述。模型仍可能自行补字，是否改善需结合实际生成结果判断。
默认版式与自定义版式均有删除按钮；删除的默认版式不进入模型清单，可通过“恢复已删除的默认版式”找回，原有用途与启停设置保留。
复制版式时保留已有槽位和轮廓，删除项不会自动补回；移动或缩放外框时槽位跟随。
自定义轮廓保存在 `panels[].shapes` 对应槽位中（中心原点 `[x,y]` 四点）。发送给 MOSS 时使用外接矩形 `bbox` 和轮廓构图描述，不是精确多边形遮罩。

- 内置坐标使用 **1088×1920 / 1920×1088** 内部画布；工作流预设和实际工作流尺寸须一致。若需要 1080p，可在工作流后处理裁切为 1080×1920 / 1920×1080。插件不自动裁切、缩放或安装模型。
- 自动配图仍返回 `images` 与 `changes`。每张图的 `tag` 是序列化 JSON，`nl` 为空。符号格式在内层顶层填写 `layout`，每个 `items` 项用 `panel`（从 1 开始的格号或位置代号）和 `slot` 引用；发送前插件将其换成原生 `bbox`，删除符号字段。
- 每个方向的可用版式、格数、读序、用途及槽位由插件注入提示词，不需要向模型发送坐标表。自定义坐标使用以画布中心为原点的 `[y_min,x_min,y_max,x_max]`。
- `E` 用于有限越线；具有 `F` 格框的面板支持动态 `X` 出框范围。`X` 外扩随格数和基准值调整并裁到画布内；这些框是生成约束，无法保证严格遮罩或准确排版。
- 原生坐标模式可在常规 ComfyUI 规范加入 `[BBI_FORMAT:MOSS_LAYOUT]`。标记不会发送到模型，`tag` 直接使用原生 Layout JSON。关闭漫画开关不会关闭这一显式标记。
- Layout 输入节点只接收完整 JSON；不要在节点输入前后拼接质量词、画师串或普通自然语言。台词、说明语言及日文手写拟声词按自定义规范设置。

### 请求缓存用量

请求历史显示输入、输出、缓存读取 token 和缓存命中率（缓存读取 ÷ 真实输入）。目前读取副 API **非流式**响应的 `usage.prompt_cache_hit_tokens` 或 `usage.prompt_tokens_details.cached_tokens`；缺失数据显示「未提供」，不当作 0%，也不使用本地估算计算命中率。流式和跟随主 API 路径暂不采集缓存数据，历史记录刷新后清空。

自动 tag 请求将稳定规则放在角色卡、玩家设定、世界书与正文之前，以减少动态资料对共同前缀的影响。实际缓存命中和延迟由服务商、模型、缓存期限及输入变化决定，插件不保证命中率或提速幅度。

在 SillyTavern 的「扩展 → 安装扩展」里填入本仓库地址即可：

```
https://github.com/baibai-git/ST-BaiBai-Image
```

安装后进入「设置」页：先到「渠道」页配置出图渠道（本地 ComfyUI 或 NovelAI 账号），再确认「自动生成 tag」开关已打开，就可以开始自动配图了。设置会随 SillyTavern 保存在服务器，跨设备自动同步。

## 小贴士

- **开箱即用**：默认设置下，只要配好出图渠道，AI 每聊一段就会自动配图；不想自动出图、只想先写 tag 的，关掉「自动生成图片」开关即可。
- **角色外貌库是自动维护的**：你不用预先录入任何角色，第一次出场时插件会自动建档；想微调再进「角色管理」页动手。固定用的角色（比如玩家）可以「提升为全局」，换个聊天也不用重新建档。
- **ComfyUI 用户**：不想碰工作流 JSON 的话，用「简易参数」模式选个模型就能出图；有自己的工作流则用 AI 自动配置功能跑通一次，之后一直复用。有多套常用配置的，存成多套随时切换。
- **NovelAI 用户**：vibe 参考图不是必须的，但能让画风/角色更稳定；`.naiv4vibe` 文件与官方互通。
- **图片数据跟着聊天走**：删聊天即删对应图片数据，隐私可控。

## 给插件作者

柏宝绘开放了一套公开接口（`globalThis.STBaiBaiImage`），别的插件可以：

- **读角色库**：拿到柏宝绘已记录的角色和可直接出图的 tag；
- **调柏宝绘出图**：后端配置、并发闸门、限流退避、图库归档全都复用，**图显示在哪由你决定**——
  画在侧边栏、画在自己的弹窗里都行，生成的图不会进入任何聊天记录。
