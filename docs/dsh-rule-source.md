# DSH 规范来源

“每轮请求指定 Skill”开启后，可展开默认折叠的“Skill 请求文案”编辑调用说明，支持恢复默认。`{{skill_id}}` 自动替换为当前入口绑定名称，成对 KEEP 保护由插件添加；留空使用默认文案。仅在漫画生成请求末尾发送一次，关闭开关或发送同步／重建控制请求时不追加。修改文案只影响新任务，正在重试的请求保留原文。此字段不改变 DSH 的 Skill 绑定。

设置 → 副 API → 指派 ST-bridge 专属接入地址 → 每轮请求指定 Skill。

- 插件规范（默认）：发送柏宝绘的固定规范和检查指导。
- DSH Skill：仅对 ComfyUI 漫画 Layout（manga）规划生效；从 DSH 请求中移除 `spec`、`check` 分组。前置提示词 `prefix`、宿主输出协议 `contract` 继续发送。
- 当前角色库与锁定信息、正文、角色卡、世界书和冷却白名单继续随每轮请求发送；图册规则见 [版式示意图接口](layout-vision.md)。
- 规范原文继续保存在插件设置中，选择 Skill 不会清空或改写它们。普通 API 和其他后端/协议不受该选项影响。

插件规范和 DSH Skill 的漫画宿主协议都使用「`<thinking>` 规划草稿 ＋ 一个外层 JSON」。成品在 `images[].tag` 直接写 Layout 对象，旧字符串也可解析。插件补齐坐标、单格格号和画布类型。锁定方向或所选版式只匹配一个方向时可省略 `size`，候选只有一套时可省略 `layout`。moss-layout-spec v7.13 起可用 `--baibaohui --require-plan` 检查这份交付。

多组顶层 `images` 按返回顺序合并，继续应用每楼图片数量和版式限制。漫画生图时跳过缺失或空白 `text` 的文字项，保留同页有效内容和台词原文。全页无可用项目时提示重新生成提示词。

## 绑定与校验

Skill 名称仍只在 DSH 的插件接入项维护，柏宝绘不新增一份绑定配置。
插件先通过当前服务的 `/v1/bridge/capabilities` 查询所选专属入口对应的 `skillId`；未绑定或入口禁用则停止发送。
随后将 `dsh_session.skill_id` 作为绑定断言传给桥接，并核对响应中的 `skill_id` 后才确认本地会话状态。
图片模式沿用同一次能力查询结果，不额外重复查询。

绑定回显仅确认 Skill 正文由桥接加载，不保证 `references/` 已被读取。
使用分册 Skill 时，须先在 DSH 侧实现分册展开或受控的资源读取能力；当前插件不读取本地 Skill 文件，也不执行其脚本。
如需重建会话，在 ST-bridge 管理。

## 会话隔离

专属入口的会话范围由 ST-bridge 设置决定。切换来源后，柏宝绘在下一次生成提供当前固定组，由桥接检测变化。网络不确定时，重试复用同一请求。
