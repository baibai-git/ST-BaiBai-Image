# 自动选版冷却

在「设置 → 漫画 Layout → 版式冷却轮数」调整窗口，默认 3，支持 0～30 轮。
0 关闭跨轮冷却，同轮多页仍须去重；修改后下一次请求生效，无需重发固定规范。
漫画 Layout 开启时，插件按酒馆聊天读取配置轮数内成功采纳的自动 tag 请求。
这些请求使用过的 layout ID 暂时不可选，同轮多页也必须使用不同 ID。
这是按 ID 避重，不比较不同 ID 的几何相似度。

- 新安装后从后续成功请求开始累计，不从旧图片推测请求次数。
- 返回结果通过验收并写入楼层后才记录；有效的无需配图结果也计一次成功判断。
- 网络错误、解析或选版验收失败、保存失败、重试、冷却放宽控制响应和固定规范同步均不计次。
- AI 单张提示词重写成功采纳后也计一次；普通重绘、手工编辑提示词不推进此窗口。
- 记录位于聊天元数据 `baibai_layout_rounds`，各聊天独立，刷新后保留；最多保存 30 次成功记录，以便调大窗口时继续使用已有记录。
- 同聊天的漫画规划串行执行，后一请求在前一请求采纳后读取记录。

插件先按启用状态、实际生成画布和方向锁筛选版式，再去掉冷却中的 ID。
若候选数不足以满足最少图片数及同轮去重，按最早记录逐步解除冷却。
即使全部解除仍不足时，会提示启用更多相容版式或降低最少图片数。

若存在候选但均不适合原文时序、槽位或文字容量，模型可以返回内部控制响应：

```json
{"images":[],"changes":[],"layout_fallback":"当前候选不适用的具体原因"}
```

宿主每次只解除最早生效的一档并重新请求。该控制响应仅在还有冷却可解除时接受，
不保存为图片、不处理其中的角色变化，也不绕过最终结果的图片数量要求。
放宽不超过配置的窗口（最多 30 轮），不会无限循环。

固定组只保留通用选版规则；动态系统消息以「本轮版式选择范围」列出可选数量、ID 及暂无候选的方向，不显示「解除 0 轮」等无效状态；列出本轮唯一可选白名单及对应的空间、槽位与用途目录。
文字目录先按当前画布、方向、启用状态与冷却筛选，放宽重试时随候选一起更新；图片模式保留不受冷却裁剪的完整图册与精简空间目录，仅更新本轮可选白名单。
每格包含实际位置、宽高与面积比例、宽高比和面积排名；斜框按多边形计算面积，需要展开的内框范围按本格 F 外接框给百分比。
空间比例仅供规划，不是输出坐标或文字容量保证；几何包含不自动等于同刻嵌入，面积大小也不自动决定叙事主次。
动态消息不带固定消息 purpose，因此普通 API、主 API 和 DSH 的每次生成都会收到更新。
修改版式几何、槽位、框用途或选择说明后，下一次请求生效；已有 DSH 会话以本轮目录覆盖历史清单，无需为版式改动重发固定规范。
DSH 普通模式修改固定规范后使用手动同步按钮；专属模式在固定组指纹变化时自动同步。同步本身不改冷却记录。

目录的格号是唯一 panel 编号；自动生成的 panel-N 位置别名不重复发送，语义位置名仍保留。
格位概览按当前实际几何生成。每格「槽位」一栏列出完整合法键名；特殊区域的相同范围可合写为 S_2/O_2，但 S_2、O_2 仍是两个独立槽位，输出不能填 S_2/O_2。
F 保留位置、宽高比、面积和排名；常规 C、主体 S、左右人物、道具及文字区仅列键名。编号区域、明显偏置或狭窄主体、非标准位置、斜框及超出实际 F 轮廓的区域保留详细范围。省略范围不代表区域无限，也不取消文字容量校验。
范围合并、目录压缩均不改动保存的版式、编译坐标、原有用途或选择说明。

所有漫画页平铺到一个最外层 images 数组，changes 只在最外层汇总；每页的 tag 是可再次解析的 Layout JSON 字符串。
外层 JSON 不完整、语法错误、多个外层对象或 images 项嵌套响应时，插件报明确错误，不从子对象中挑选部分页面。
协议验收失败时，请求历史仍保存返回文本和已获得的上游 usage；文本沿用既有的 20000 字符显示上限。
