# 自动选版冷却

在「设置 → 漫画 Layout → 版式冷却轮数」调整窗口，默认 3，支持 0～30 轮。
0 关闭跨轮冷却，同轮多页仍须去重；修改后下一次请求生效，无需重发固定规范。
漫画 Layout 开启时，插件按酒馆聊天读取配置轮数内成功采纳的自动 tag 请求。
这些请求使用过的 layout ID 暂时不可选，同轮多页也必须使用不同 ID。
这是按 ID 避重，不比较不同 ID 的几何相似度。

- 新安装后从后续成功请求开始累计，不从旧图片推测请求次数。
- 返回结果通过验收并写入楼层后才记录；有效的无需配图结果也计一次成功判断。
- 网络错误、解析或选版验收失败、保存失败、重试、冷却放宽控制响应和固定规范同步均不计次。
- AI 单张提示词重写成功采纳后也计一次；普通重绘、手工编辑提示词不推进此窗口。
- 记录位于聊天元数据 `baibai_layout_rounds`，各聊天独立，刷新后保留；最多保存 30 次成功记录，以便调大窗口时继续使用已有记录。
- 同聊天的漫画规划串行执行，后一请求在前一请求采纳后读取记录。

插件先按启用状态、实际生成画布和方向锁筛选版式，再去掉冷却中的 ID。
若候选数不足以满足最少图片数及同轮去重，按最早记录逐步解除冷却。
即使全部解除仍不足时，会提示启用更多相容版式或降低最少图片数。

若存在候选但均不适合原文时序、槽位或文字容量，模型可以返回内部控制响应：

```json
{"images":[],"changes":[],"layout_fallback":"当前候选不适用的具体原因"}
```

宿主每次只解除最早生效的一档并重新请求。该控制响应仅在还有冷却可解除时接受，
不保存为图片、不处理其中的角色变化，也不绕过最终结果的图片数量要求。
放宽不超过配置的窗口（最多 30 轮），不会无限循环。

固定清单仍保留完整几何字典；动态系统消息列出本轮唯一可选白名单。
动态消息不带固定消息 purpose，因此普通 API、主 API 和 DSH 的每次生成都会收到更新。
DSH 修改固定规范后仍使用原来的手动同步按钮；同步本身不改冷却记录。
