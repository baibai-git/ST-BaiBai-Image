# 版式导入导出

0.3.9 起，在“设置 → 漫画 Layout”的批量画布区域下方使用：

- **导出全部版式**：下载一个 JSON 文件，包含当前列表的启用及停用版式，并记录已删除默认版式的状态。
- **导入版式**：选择全部版式文件或单套版式文件；也支持版式数组和 ComfyUI 节点的 panels 格式。
- **导出当前版式**：位于每套版式的“可视化编辑”旁，下载该套版式的完整 JSON。

文件保留实际横竖方向、画布尺寸、外框与内框坐标、变形角点、读序、层级及框说明。内置版式导出时也保存实际坐标，便于独立导入。单套文件可直接使用现有 JSON 版式编辑器解析。

导入先校验全部条目。文件损坏、重复 ID、非法坐标或启用状态不合法时，不会部分修改本地库。同名版式确认后覆盖，文件中明确删除的默认版式按记录隐藏；其他本地版式保留。单套文件没有 enabled 字段时，沿用现有启用状态。

请先保存或取消当前编辑，再使用导入导出按钮。导入后的列表立即更新，下次生成使用新几何；已生成的图片不受影响。

这些文件仅包含版式数据，不包含提示词规范、检查指导、API 密钥或聊天资料。隐藏 G 辅助区由插件按 F 推导，不写入文件。

验证：1012 项测试通过、3 项跳过，类型检查及生产构建通过；覆盖整库往返、单套编译、形变及启用状态保留、损坏文件与覆盖取消。手机端实际文件下载／选择体验仍需实机验证。
